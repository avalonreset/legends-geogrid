# Support

## Getting Help

- **Documentation:** Start with [README.md](README.md) and the guides in `docs/`.
- **Ecosystem Router:** Run `cto-legends handoff legends-geogrid` and `cto-legends doctor`.
- **Community:** Join [AI Marketing Hub Pro](https://www.skool.com/ai-marketing-hub-pro/about) for live workflows and architecture discussions.
- **Bug Reports:** Open an issue in [avalonreset/legends-geogrid](https://github.com/avalonreset/legends-geogrid/issues) with your OS, Python version, and command output.

## Scope Boundaries

Maintainers do not accept private API keys, credentials, or unredacted client data in issues or pull requests. For security vulnerabilities, follow [SECURITY.md](SECURITY.md).
