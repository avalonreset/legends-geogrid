# Start a useful GeoGrid study

## 1. State the decision

Write one sentence: which service, which market, and what decision will change after measurement? Do not promise a website recovery diagnosis from Maps ranks.

## 2. Establish identity and geography

Resolve an exact CID, place ID, or canonical domain. Record the verified business base separately from advertised cities and practical service territory. For mobile services, obtain departure town, travel constraints and viable booking types. Unknown facts remain unknown. A market-centered exploratory study is valid when explicitly commissioned and labeled; never present its center as a verified business address.

## 3. Run bounded discovery before a dense grid

Check branded identity and representative service queries. Where relevant, check organic website visibility separately. Review whether returned competitors actually supply the service. Record result depth, zoom, language, device and search-this-area setting. If controls conflict, change one setting at a time and preserve each run separately.

## 4. Choose the useful route

- Relevant local results and a defined coverage question: select comparable origins and run a grid.
- Sparse, irrelevant, or strongly setting-sensitive results: calibrate and disclose limitations before scaling.
- Organic visibility with weak Maps evidence: consider a website and enquiry review first.
- Unknown practical territory: request the missing business facts or deliver a provisional discovery brief. Do not infer profitable travel from ranking positions.

A discovery brief can be one page: question, verified facts, bounded observations, unknowns, recommended next action. It is a valid outcome without a dense scan.

## 5. Collect and report

Estimate cost before execution. Use fixed sampling for repeat comparisons and adaptive expansion for a stated reach question. All compared queries share locations and settings. Keep controls separate. Use the normalized report contract in `examples/reports/README.md`; configure a registered basemap if street geography is required. Preserve evidence, observed depth and missing-data states.

## 6. Accept the output

Inspect every PDF page at reading size. Check map registration, readable labels, intact rings and attribution, text fit, and no em dashes. Verify counts against evidence. Close with what was learned, one supported next action, and the missing evidence that could change it. Never manufacture a confident prescription from ranks alone.

These steps are operator guidance, not automated market-fit enforcement. See [report acceptance](REPORT_ACCEPTANCE.md) and [product limitations](PRODUCT_STATUS.md).
