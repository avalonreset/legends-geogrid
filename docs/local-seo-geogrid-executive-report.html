FIG. 06

Square grid, radius, and why the shape looks rectangular sometimes

The paid scan should stay square because that is the repeatable sampling model: 3 x 3, 5 x 5, 9 x 9, 17 x 17. Radius controls how far the points extend from the center.

On a screen, the grid can look rectangular because the map viewport, latitude and longitude scaling, and screenshot crop are not a perfect physical square. The underlying coordinate lattice is still square in point count.

Risks and guardrails

Matching risk

Use CID or place ID when possible

Name matching alone can miss a listing. Domain, CID, and place ID make the match stronger.

Freshness risk

Date every scan

Demo data can stay historical. Prospect outreach should usually refresh after 7 to 30 days.

Do not build a direct Google Maps scraper as the rank backbone. DataForSEO is the cleaner path because it absorbs the retrieval, proxy, CAPTCHA, and maintenance burden.

The recommended move

Run the first paid bulk proof only on a real prospect list. Pick one vertical and geography, use 5 x 5 Standard for a $15 proof, or use 9 x 9 Standard if we want the strongest 1,000-prospect proof inside a $50 budget.
